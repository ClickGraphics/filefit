# FileFit

FileFit hace que una imagen cumpla requisitos concretos de formato, dimensiones y peso máximo desde una sola interfaz.

## V0.1

- JPG, PNG y WebP.
- Conversión de formato.
- Redimensionado por ancho y/o alto.
- Recorte centrado para dimensiones exactas.
- Compresión JPG/WebP hasta un peso máximo objetivo.
- Verificación del resultado antes de descargar.
- Procesamiento 100% local mediante Canvas API.
- Sin backend, base de datos, cuentas ni APIs de pago.
- Mobile-first.

## Privacidad

Los archivos seleccionados no se envían a FileFit ni a un servidor. El navegador realiza el procesamiento localmente.

## Ejecutar

Es un sitio estático sin dependencias. Abre `index.html` en un navegador moderno o publícalo en cualquier hosting estático.

## Estado económico

Coste de software e infraestructura requerido por el MVP: **$0**.
